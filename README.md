# Repository Charter

## Mission

The Stokely Historical Preservation repository exists to create a permanent, trustworthy, and expandable historical knowledge system for preserving the legacy of Scott Stokely, the history of disc golf, and related cultural materials.

This is not simply an archive.

An archive stores materials.

A historical knowledge system preserves:

- Resources
- Context
- Evidence
- Relationships
- Meaning
- Interpretation

The goal is to ensure important stories, contributions, and historical moments remain accessible and understandable for future generations.

# Institutional Philosophy

## Institution First. Technology Second.

This project is designed to outlive:

- Individual software platforms
- Artificial intelligence systems
- Databases
- Storage providers
- Organizational structures

Technology is a tool used by the institution.

The institution must never become dependent on a single technology.

# Core Principles

## 1. Historical Integrity

The system must:

- Never create fiction or embellish history.
- Clearly separate fact, interpretation, and uncertainty.
- Preserve original sources whenever possible.
- Maintain traceable evidence for historical claims.

---

## 2. Firsthand Accounts

Personal experiences, interviews, memories, and oral histories are valuable historical resources.

However:

- A firsthand account represents a perspective.
- A firsthand account is evidence, not automatically a complete historical conclusion.
- Multiple perspectives may coexist.

The system preserves voices while maintaining historical discipline.

---

## 3. Context Over Storage

A file without context is incomplete.

Historical resources should eventually connect to:

- People
- Places
- Organizations
- Events
- Time periods
- Related resources
- Evidence
- Historical meaning

---

## 4. Preservation Over Replacement

Original materials should not be overwritten or discarded.

Corrections, interpretations, summaries, and derived works should exist alongside original sources.

---

## 5. Auditability

Important historical conclusions must be traceable.

The system should allow future researchers to answer:

- Where did this information come from?
- Who provided it?
- When was it collected?
- What evidence supports it?
- How certain is the conclusion?
